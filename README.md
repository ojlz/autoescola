# Autoescola — Landing Page (projeto fictício)

> **Aviso:** site 100% fictício criado para portfólio. Nome, endereço
> (Av. das Acácias Fictícias, 000 — Porto Fictício/EX), telefone
> `(00) 90000-0001`, WhatsApp, CNPJ `00.000.000/0001-00`, mapas e avaliações
> são inventados. Nenhum dado é real e não representa nenhuma empresa.

🌐 **Demo no ar:** https://autoescola-ex.vercel.app

Landing page de um Centro de Formação de Condutores fictício: 1ª CNH (A/B),
adição e mudança de categoria (D/E), renovação, planos e contato via WhatsApp.

## Stack

- HTML + CSS + JS puros (sem build)
- SEO: meta tags, Open Graph, JSON-LD, `sitemap.xml`, `robots.txt`, `llms.txt`

## Estrutura

| Arquivo      | O quê           |
| ------------ | --------------- |
| `index.html` | Página completa |
| `styles.css` | Estilos         |
| `script.js`  | Interações      |

## Rodar local

Abra `index.html` no navegador ou sirva a pasta:

```bash
npx serve .
```

## Deploy

Hospedado na Vercel (projeto `autoescola-ex`). Qualquer push na branch
principal dispara redeploy automático.
